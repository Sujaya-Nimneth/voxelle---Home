# Voxelle Home → Enterprise-Grade Portfolio Project

**Goal:** Transform the current UI prototype into an honestly-marketed, strictly-typed, tested, accessible, CI-deployed portfolio piece. All four scope decisions confirmed: full TypeScript, real Ollama/LM Studio wiring with honest fallback, Vitest+RTL+Playwright, CI + GitHub Pages demo.

Each phase ends with the app building, linting, and tests green, and gets one conventional commit. Test infrastructure (Vitest) lands in Phase 1 so every later phase adds its own regression tests as it goes.

---

## Phase 1 — TypeScript migration + test infrastructure

**TS setup:** Add `typescript`, `@types/canvas-confetti`. `tsconfig.json` (strict, `jsx: react-jsx`, bundler module resolution, `noUncheckedIndexedAccess`). `typecheck` script (`tsc --noEmit`). Migrate all 14 files in dependency order — `allowJs` during the sweep, strict-only at the end:

1. `src/types/index.ts` — `Device`, `DeviceCategory`, `Camera`, `Scene`, `Automation`, `ChatMessage`, `AiProvider`, `AiAction`, `AiResult`, `ViewId`, `DeviceFrame`, `Wallpaper` unions.
2. `services/localAiEngine` → typed.
3. `context/HomeContext` → typed (structure unchanged this phase).
4. All 12 components → `.tsx` (typed props from context types).

**Test infra:** Vitest + jsdom + @testing-library/react + user-event; `npm test` script. First tests: built-in rule engine intent parsing ("dim living room lights to 25%" → correct actions), Ollama connection check with mocked `fetch` (ok / not-running / timeout).

**Hygiene:** Delete dead code — `src/App.css`, `src/assets/hero.png`, `src/assets/react.svg`, `src/assets/vite.svg`, `public/icons.svg` (verified unreferenced), ~16 unused icon imports, unused `porchCam` var. `package.json`: name → `voxelle-home`, version `0.1.0`, `engines.node >=22`. Add `.nvmrc` (22), `.editorconfig`.

## Phase 2 — Architecture refactor + state bugs

**Split the 503-line context:**

- `src/data/seedDevices.ts`, `seedCameras.ts`, `seedScenes.ts`, `seedAutomations.ts`, `rooms.ts` (single room-list constant, dedupes `HomeDashboard` + `Sidebar`).
- `src/store/homeReducer.ts` — pure reducer (devices, scenes, cameras, automations, UI state).
- `HomeContext.tsx` — thin provider: **memoized context value** (`useMemo` + `useCallback` actions; fixes re-render-everything), `useReducer` driving the reducer.
- **Persistence:** versioned `localStorage` (`voxelle-home-state-v1`) with try/catch; "Reset demo home" button in header/settings.
- **Bug fixes landed here:**
  - Automations move into context (generated automations survive navigation; sidebar `"4"` badge becomes derived count).
  - `toggleDevice` syncs `selectedDevice` (stale-modal bug, `HomeContext.jsx:347`).
  - `climateSummary` derived from actual thermostat state (was constant `'68° - 72°'`).
  - Timer/speech cleanup: `CameraDetailModal` snapshot timeout, `AutomationsView` synth timeout, stop recognition + cancel `speechSynthesis` on modal unmount.
- **`App.tsx` dedupe:** extract `<GlobalModals />` (currently triplicated), data-driven `IPhoneTabBar` (four copy-pasted buttons), shared chassis layout skeleton. Consolidate duplicated AI-orb/Add-Accessory header actions (TopHeader vs HomeDashboard).
- **Root `ErrorBoundary`** with styled fallback + reload.
- **CSS split (class names unchanged — no visual regression):** `styles/tokens.css` (variables, keyframes incl. **missing `spin` + `spin-anim`**, reset), `layout.css`, `components/*.css` (sidebar, tiles, cameras, modals, automations, discover, chassis).

Tests: reducer action suite (toggle/update/scene applies correct mutations, automation add/toggle, persistence round-trip + version reset).

## Phase 3 — Real AI providers + honest engine

Rewrite `services/localAiEngine` into `src/services/ai/`:

- `providers/builtinRuleEngine.ts` — today's keyword matcher, honestly renamed "Built-in rule engine (offline)" in UI copy; **replies derive from actual device state** (delete fabricated "99% confidence", "82°F", "69°F" strings).
- `providers/ollama.ts` — `/api/tags` health + `/api/chat` completion with a structured prompt that returns device actions; `providers/lmstudio.ts` — `/v1/models` + `/v1/chat/completions`. Both: shared provider interface, `AbortController` + 8s timeout, typed errors, **measured** latency (delete hard-coded "3ms/42ms/38ms").
- **Provider switching actually routes** `processCommand` through the selected provider; dead `lmStudioUrl`/`selectedModel` fields become functional (model picker from `/api/tags`).
- **Honest error UX:** the fake-success catch (`LocalAiModal.jsx:164` — currently posts "Local inference processed. Home state verified.") becomes a visible error bubble with a one-click "fall back to offline engine" affordance. `checkOllama` gets stale-guard + timeout.
- Endpoints via `import.meta.env` (`VITE_OLLAMA_URL`, `VITE_LMSTUDIO_URL`), `.env.example` added.
- Camera feeds: keep simulated images but add a subtle "Demo feed" tag — no fake liveness.

Tests: provider modules against mocked fetch (success, timeout, offline), fallback routing, regression test for the fake-success bug.

## Phase 4 — Accessibility (WCAG 2.1 AA targets)

- Clickable `<div>`s → `<button>` with preserved styles: accessory tiles, camera cards, sidebar nav items.
- `useModalDialog` hook for all 3 modals: ESC close, focus trap, focus restore, `role="dialog"` + `aria-modal` + `aria-labelledby`.
- `aria-live="polite"` on AI chat stream; automation toggle → `role="switch"` + `aria-checked`; landmarks (`nav`/`main`/`aside` with labels).
- Remove `maximum-scale=1.0, user-scalable=no` (`index.html:6`); scope `user-select: none` so chat/input text stays selectable; visible `:focus-visible` ring token.
- Replace `alert()` ("Add Accessory", speech fallback) with a small styled toast system.

## Phase 5 — Performance

- **Images (5.4MB → target <1MB):** `sharp` devDep + `scripts/optimize-images.mjs` (resize ≤1600px, WebP q≈72); camera JPGs → WebP, `loading="lazy"` + `decoding="async"` + explicit dimensions; wallpapers as WebP.
- **Fonts:** self-host via `@fontsource-variable/inter` + `@fontsource/jetbrains-mono`; delete Google Fonts `<link>` and CSS `@import` (currently double-loaded); wire the unused `--font-mono` token to JetBrains Mono. Removes the external CDN call that contradicts the privacy claim.
- `React.memo` on `AccessoryTile`/`CameraCard`; vite `build.rollupOptions` vendor chunk for react.

## Phase 6 — E2E tests (Playwright)

`playwright.config.ts` against built preview; smoke spec: dashboard loads → toggle a light tile → state changes → open device modal → open AI modal, send command via built-in engine → switch chassis → automations view still shows generated automation (regression for the vanish bug). `test:e2e` script; browser binaries installed locally.

## Phase 7 — Tooling, CI, GitHub Pages deploy, docs

- **Quality gates:** Prettier + `format` script; expand oxlint (correctness category + `no-unused-vars` as error); husky + lint-staged pre-commit (lint + format staged files).
- **CI (`.github/workflows/ci.yml`):** PRs + main — Node 22: `npm ci` → lint → typecheck → test → build → Playwright (with browser cache).
- **Deploy (`deploy.yml`):** push to main → build → GitHub Pages. Vite `base: './'` (no router, so relative base works with the `voxelle---Home` repo slug).
- **Repo files:** `dependabot.yml`, issue templates, PR template, CONTRIBUTING.md, SECURITY.md, CHANGELOG.md (Keep a Changelog).
- **README truth pass:** live-demo badge + screenshots, honest capability table (mark simulated: camera feeds/vision, automation execution; real: Ollama/LM Studio chat, Web Speech, rule engine), remove "sub-5ms semantic parsing / WebGPU / 100% on-device intelligence" claims, document env vars + test/CI commands.
- **PWA/SEO basics:** `manifest.webmanifest`, real description/OG tags (README currently claims PWA meta that barely exists).

## Phase 8 — Final verification

All gates green locally (lint, typecheck, unit, e2e, build); manual visual pass across the three chassis via dev server; verify Pages deployment; final README screenshots; tag `v0.1.0`.
